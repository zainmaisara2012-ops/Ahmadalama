# منصة الأستاذ أحمد الأعمى

صفحة عربية لعرض الكتب للطلاب، ولوحة إدارة لإدارة الكتب وأكواد التفعيل. المشروع يستخدم Firebase وتهيئة جاهزة للنشر على GitHub Pages.

ابدأ بقراءة **[دليل الإعداد العربي](دليل-الإعداد.md)**؛ فهو يشرح إعداد حساب المدير والقواعد ورقم واتساب والتشغيل والنشر والقيود والتكاليف المحتملة.

- `docs/index.html`: صفحة الطلاب.
- `docs/admin/index.html`: صفحة الإدارة.
- `docs/shared/config.js`: إعدادات Firebase ورقم واتساب.
- `firestore.rules` و`storage.rules`: قواعد الحماية التي يجب نشرها في Firebase.
- `cors.json`: إعداد الوصول إلى ملفات PDF من المتصفح بعد تعديله وتطبيقه على حاوية Storage.

المنصة غير مربوطة بحساب حقيقي عند تنزيلها. لا تضع كلمات المرور أو مفاتيح الخدمة السرية أو ملفات الكتب داخل GitHub.
